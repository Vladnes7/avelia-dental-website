# АВЕЛИЯ

36 страниц вымышленной стоматологии в Москве. Next.js App Router, TypeScript, Motion и неизменённый runtime scroll-craft. Кириллические Manrope и Onest загружаются локально.

## Просмотр

`npm run dev -- --port 4173` → http://127.0.0.1:4173

После клонирования выполните `npm ci`, затем `npm run build` и `npm run start -- --port 4173`. Для просмотра локальный сервер должен оставаться запущенным.

## Проверка

`npm test` · `npm run typecheck` · `npm run build`

Оптимизированные WebP, миниатюры и манифест в `public/images` включены в репозиторий: после клонирования сайт запускается с фотографиями. PNG-исходники хранятся локально. `npm run images` используется только при наличии `_материалы/фото/исходники` и создаёт WebP и контактный лист заново.

## Содержание

9 общих страниц +10 услуг +8 врачей +9 статей. Реестр маршрутов: `src/lib/routes.ts`. Демонстрационный календарь: Europe/Moscow, 30 дней, доступность одного врача и услуги проверяется перед локальным подтверждением. Форма не отправляет и не сохраняет персональные данные. Рейтинг, отзывы, адрес, врачи и цены вымышлены.

Тема сохраняется в localStorage. Hero и журнал останавливаются при наведении, фокусе, скрытой вкладке и уходе за экран; услуги листаются вручную. `prefers-reduced-motion` отключает параллакс и автоматическое движение. Меню удерживает фокус, закрывается Escape и возвращает фокус кнопке. Графики восьми врачей и календарь используют единый источник рабочих дней.
